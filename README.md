## Цели и задачи

В рамках лабораторной работы ставится задача создания программных средств, поддерживающих эффективное хранение разреженных матриц в формате **CRS (Compressed Row Storage)** на базе контейнера `std::vector` и выполнение основных операций над ними:

- конвертация из плотного представления (двумерного вектора) в формат CRS и обратно;
- копирование, присваивание и сравнение;
- доступ к элементам матрицы по индексам (с учётом разреженной структуры);
- транспонирование разреженной матрицы без перехода к плотному формату;
- умножение разреженной матрицы на плотный вектор (`SpMV`);
- умножение двух разреженных матриц в формате CRS с получением результата в формате CRS (`SpGEMM`).

### Краткая справка о формате CRS

Формат **CRS (Compressed Row Storage)** (также известный как CSR — *Compressed Sparse Row*) предназначен для экономичного хранения матриц с большим количеством нулевых элементов. Матрица размера `rows x cols`, содержащая `NNZ` (Number of Non-Zeros) ненулевых элементов, хранится с помощью трёх одномерных массивов (`std::vector`):

1. `values` (размер `NNZ`) — значения ненулевых элементов, записанные подряд по строкам слева направо, сверху вниз.
2. `col_index` (размер `NNZ`) — столбцовые индексы соответствующих элементов из массива `values`.
3. `row_ptr` (размер `rows + 1`) — индексы в массивах `values` и `col_index`, с которых начинается очередная строка матрицы. При этом `row_ptr[0] = 0`, `row_ptr[rows] = NNZ`, а количество ненулевых элементов в `i`-й строке равно `row_ptr[i + 1] - row_ptr[i]`.

## Общая структура проекта

Структура проекта:

  - `docs` — инструкции по выполнению лабораторной работы, полезные документы.
  - `gtest` — библиотека Google Test.
  - `include` — директория для размещения заголовочных файлов.
  - `samples` — директория для размещения тестового приложения.
  - `sln` — директория с файлами решений и проектов для Visual Studio.
  - `test` — директория с модульными тестами и основным приложением,
    инициализирующим запуск тестов.
  - `README.md` — информация о проекте, которую вы сейчас читаете.
  - Служебные файлы:
    - `.gitignore` — перечень расширений файлов, игнорируемых Git при добавлении
      файлов в репозиторий.
    - `CMakeLists.txt` — корневой файл для сборки проекта с помощью CMake.
    - `.travis.yml` — конфигурационный файл для системы автоматического
      тестирования Travis-CI. Тесты, входящие в состав шаблонного проекта,
      регулярно запускаются на удаленной [инфраструктуре][travis].

В решении содержатся следующие модули:

  - Модуль `tmatrix`, содержащий реализацию шаблонного класса разреженной матрицы `TCRSMatrix` (файл `./include/tmatrix.h`). Поскольку класс шаблонный, реализацию методов необходимо выполнять непосредственно в заголовочном файле. При этом интерфейс класса должен оставаться неизменным.
  - Модульные тесты для класса `TCRSMatrix` (файл `./test/test_tmatrix.cpp`).
  - Пример использования класса `TCRSMatrix` (файл `./samples/sample_matrix.cpp`).
